Open source projects: certificate management and PKI tools, Go libraries for PKI protocols and activity monitors for social, music and gaming platforms.

Certificate management and PKI

Tools and integrations

  • DocsCodecertrallyCommand line client for CMP, EST and SCEP certificate enrollment with test CAs, RFC checks and post-quantum keys
  • DocsCodecmp-issuerKubernetes cert-manager issuer for CMP servers
  • DocsCodencm-issuerKubernetes cert-manager issuer for Nokia NCM PKI
  • Codeforklift_x509_toolsForkLift (macOS) extensions for managing X.509 certificates

Go libraries

  • DocsCodego-acme-serverEmbeddable ACME server (RFC 8555)
  • DocsCodego-pki-cmpCertificate Management Protocol (RFC 9810, RFC 4210 and RFC 6712)
  • DocsCodego-pki-estEST client and embeddable server (RFC 7030 and RFC 8951)
  • DocsCodego-pki-scepSCEP client and embeddable server handler (RFC 8894)
  • DocsCodego-pkcs7PKCS #7 and CMS signed and enveloped data (RFC 5652)
  • DocsCodego-composite-mldsaPost-quantum composite ML-DSA signatures (draft-ietf-lamps-pq-composite-sigs)
  • DocsCodego-tls-srpTLS 1.2 client and server with SRP password authentication (RFC 5054)
